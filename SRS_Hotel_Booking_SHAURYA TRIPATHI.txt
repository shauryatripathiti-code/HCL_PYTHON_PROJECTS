Project  : Hotel Bookings Analysis (Hospitality / Tourism)

Date     : 21 November 2026
Version  : 1.0

--------------------------------------------------------------------------------
1. INTRODUCTION
--------------------------------------------------------------------------------
Purpose : Analyse room reservations, stay durations, booking channels and
          cancellations to help a hotel optimise room pricing and front-desk
          staffing.
Scope   : A Python script (hotel_analysis.py) that reads one CSV file, cleans
          the data, calculates the required statistics and prints the results
          and five recommendations in the terminal. It writes no files.

--------------------------------------------------------------------------------
2. OVERALL DESCRIPTION
--------------------------------------------------------------------------------
Input    : 13_hotel_bookings.csv - 612 rows, 12 columns, 2025 bookings
           (Booking_ID, Guest_ID, Booking_Date, Checkin_Date, Nights,
           Lead_Time_Days, Room_Type, Guests, Booking_Channel, Travel_Purpose,
           Room_Rate, Booking_Status)
Output   : Text in the terminal only.
Users    : Student / analyst running the script; hotel management reading the
           results.
Platform : Python 3.10+, Visual Studio Code, any operating system.
Libraries: pandas and NumPy only.
Constraints / assumptions:
  - Simple beginner-style code (no classes or custom functions).
  - Data is synthetic; the hotel is assumed to have 12 rooms.
  - Only Booking_Status "Canceled" counts as canceled.

--------------------------------------------------------------------------------
3. FUNCTIONAL REQUIREMENTS
--------------------------------------------------------------------------------
FR-1   Load the CSV and show shape, first rows and column info.
FR-2   Report missing values and duplicate Booking_ID rows; remove duplicates.
FR-3   Fill missing Lead_Time_Days (recalculate from Checkin_Date minus
       Booking_Date) and Room_Rate (median of the same Room_Type).
FR-4   Convert Checkin_Date to datetime; extract arrival month and weekday.
FR-5   Calculate total bookings, total room nights and cancellation %.
FR-6   Calculate revenue = Nights x Room_Rate for non-canceled bookings.
FR-7   Compare average room rate and occupancy across room types.
FR-8   Rank booking channels by booking volume and by revenue.
FR-9   Show cancellation rates by booking channel and lead-time band.
FR-10  Find the top 3 peak revenue months.
FR-11  Compare average stay of leisure and business travellers.
FR-12  Use NumPy to get mean, median and standard deviation of daily rates.
FR-13  Find unusually high booking values with the IQR method.
FR-14  Create lead-time categories with pd.cut() (Last-Minute, Short-Term,
       Medium, Advance).
FR-15  Print five revenue and operations recommendations.
Extra  Monthly occupancy trend and arrivals by weekday.

--------------------------------------------------------------------------------
4. NON-FUNCTIONAL REQUIREMENTS
--------------------------------------------------------------------------------
  - Easy to read: one short block per task, with comments.
  - Fast: finishes in a few seconds.
  - Reliable: runs from start to end without errors or warnings.
  - Safe: does not change the input file or create any file.

--------------------------------------------------------------------------------
5. HOW TO RUN
--------------------------------------------------------------------------------
  1. Put hotel_analysis.py and 13_hotel_bookings.csv in the same folder.
  2. pip install pandas numpy        (first time only)
  3. python hotel_analysis.py
